# Shared native core review

This historical `6945cad7` checkpoint adds historical typed market snapshots, intent/risk/cancellation helpers and a shared metadata graph to the native arithmetic, metrics, Portfolio and batch statistics foundation. It does not certify the complete strategy SDK, a running native strategy, production live execution, replay input preparation, fleet deployment or a production speed multiplier. Every whole integration requirement remains pending or in progress.

The subsequent SDK/admission checkpoint is documented in [SDK admission review](./SDK-ADMISSION-REVIEW.md); its updated evidence closes the derived-nonfinite probe gap and adds typed records, callback admission and bounded local Parquet IO. Authoritative Portfolio aliases and full runtime integration remain pending.

The TypeScript reference remains `07245602d6ff9bca0dcdf772134cba3dd227526c`. Independent reviewers exercised the same frozen native source set as the integrated validation report. All recorded current native/wrapper hashes were checked again before these reports were stored.

The earlier checkpoint repaired eight P2 helper findings: stale executable provenance, radix conversion rounding, checked conversion failures, incomplete UTF16 response counts, Portfolio binary64 normalization, terminal reason validation, metadata signed zero and the associated comparator coverage. Their original review evidence remains historical; refreshed current reports are authoritative for this checkpoint.

The metadata arena uses explicit roots, non-owning internal edges and incremental tracing/sweeping. Its collection tests cover cycles, root/write barriers, stale weak handles and sustained churn. It does not implement a general JavaScript interpreter or certify arbitrary prototypes, accessors, descriptors, functions or custom `toJSON`. Those usage/compatibility requirements cannot be silently retired.

Portfolio records and their metadata must join the same session identity graph. A detached JSON mirror or a second independently reference-counted graph cannot preserve the observed record/metadata aliases and cycles. Snapshot membership wrappers, mutable records, replacement history records and frozen capital overlays require distinct identity behavior. Market payload allocation reuse also does not establish JavaScript wrapper identity.

## Evidence and reproduction

Current reports are `evidence/core-validation.json`, `core-market.json`, `core-portfolio.json`, `core-intents.json`, `core-math-{debug,release}.json`, `core-metrics-{debug,release}.json`, `core-metadata-{debug,release}.json` and `core-stats.json`.
