- `LOG_TRADES`

## Notes

- Prefer documented defaults in code (`src/polymarket/config.ts`, `src/config/env.ts`, CLI entry files).
- If running multiple bots, keep shared values in `.env` and bot-specific overrides in `.env.<bot>`.
