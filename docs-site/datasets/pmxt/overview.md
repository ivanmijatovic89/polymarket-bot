# PMXT Overview

::: warning Documentation in progress
This section is being written. The implementation is available on the current branch — docs will follow shortly.
:::

PMXT is a dataset source for the backtest engine. Like Telonex, it provides pre-collected historical order book data that can be replayed through the same strategy and engine code used in live trading.

Full documentation covering the data format, download workflow, and backtest integration will be added here once the implementation is complete.
