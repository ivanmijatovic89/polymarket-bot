# llm-usage

Shows subscription rate-limit usage (5h / weekly / weekly Fable-Opus windows)
for Claude Code and Codex accounts.

```bash
npm run llm-usage   # from the repo root
```

Full documentation — accounts.json reference, adding accounts, caveats —
lives in [`docs/other/llm-usage.md`](../../docs/other/llm-usage.md).
