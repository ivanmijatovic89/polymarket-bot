**Findings (most severe first):**

1. **MAJOR (internal inconsistency; affects the unlock threshold): the entry's "why parked" numbers and its unlock threshold use two different variance conventions, and the 15,000 figure fails under the convention the entry itself computes with.** The 1.9c / 23% / 35% / 3,360 / 28,000 figures all reproduce exactly and ONLY under the Bernoulli convention: se = √(0.2358/660) = 1.89c; power at +2.38c = Φ(2.38/1.89 − 1.995) = 0.231; at α = 0.05, Φ(1.259 − 1.645) = 0.350; 80% power needs se = 2.38/(1.995+0.842) = 0.839c → n = 0.2358/0.00839² = 3,351 ≈ 3,360 → 3,351/0.1209 = 27,718 ≈ 28,000. But the unlock power at 15,000 markets and true net +2c is: n = 15,000·0.1209 = 1,814 → Bernoulli se = 1.140c, z = 1.754, power = Φ(−0.241) = **40.5%** — below the stated "≥ ~50%". Under the Table convention it is se = 0.920c, z = 2.173, power = Φ(0.178) = **57.1%** — the only convention under which "15,000 → ≥50%" holds. Under one consistent convention the written pair (28k for 80%, 15k for 50%) cannot both be right: Bernoulli gives (28k, **19.4k**); Table gives (**18.1k**, 12.6k). If the eventual pre-registered test uses the scan's own z (Table se, which is also the statistically correct null), the 15k unlock is fine but the 28k/"~5× the reserve" claim overstates the requirement (18.1k ≈ 3.3× the reserve). If the entry insists on the Bernoulli convention, the unlock threshold must rise to ~19,500–20,300 markets. Either way one bullet needs correcting.

2. **MINOR (denominator slip in reserve-yield projection): n ≈ 660 uses per-SAMPLED-market incidence on a count of ELIGIBLE markets.** Incidence 983/8,133 = 12.09% ≈ 12.1% ✓ (the entry correctly says "of sampled markets, coverage included"). But 5,460 is the eligible reserve; CAL-001's emitting fraction is 8,133/8,516 = 95.5%, so the correct projection is 5,460·0.955·0.1209 ≈ **630**, not 660 (5,460·0.1209 = 660.1 — the entry's arithmetic, ~4.7% optimistic). Downstream effect is negligible and in the conservative direction for the park: at n = 630, Bernoulli power at +2.38c is 22.2% (vs stated 23%), Table 31.9%. Does not change any decision; the same 95.5% factor pushes the 28k figure to ~29k and the consistent-Bernoulli unlock to ~20.3k.

3. **MINOR (understated power under the correct convention — park still licensed): at the Table convention the reserve test has ~33% power, not ~23%.** se = √(0.1536/660) = 1.53c (1.56c at n = 630); power at +2.38c = 33.2% at α = 0.023 (46.6% at α = 0.05). The entry says exactly this ("winner's curse biases it upward; true power is lower"). Correct in direction and logic.

5. **MAJOR for the proposed GENERAL claim (item h — not currently written anywhere; do NOT write it as stated): "no 1.5–2.4c-net effect could be confirmed on the reserve with ≥50% power at typical incidences" is FALSE as a universal, in two ways.** Detectable-at-50%-power effect = 1.995·se on the reserve (5,460 eligible; I use n = 5,460·incidence, i.e., the entry's own optimistic denominator — the 95.5% correction only strengthens the claim where it holds):
   - incidence 10% (n = 546): Bernoulli se = 2.08c → detectable ≥ 4.15c; Table se = 1.68c → 3.35c. Claim HOLDS (whole 1.5–2.4c range unconfirmable; power at 2.4c = 20%/29%).
   - incidence 20% (n = 1,092): Bernoulli se = 1.47c → 2.93c (holds); Table se = 1.19c → **2.37c** — a 2.4c effect is at 51% power, i.e., the claim already fails marginally at the top of the range under the test's own convention.
   - incidence 50% (n = 2,730): Bernoulli se = 0.93c → 1.85c (2.4c effect: 72% power); Table se = 0.75c → **1.50c** (2.4c effect: 89% power; even 1.5c hits 50%). Claim FAILS clearly.
   Second failure mode: the 0.15–0.24 per-sample variance is specific to mid-priced cells (a ≈ 0.6).
