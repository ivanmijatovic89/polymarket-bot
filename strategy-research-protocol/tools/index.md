# Tools

`strategy-research-protocol/tools/` defines executable repository tools
available to AI agents while working with the strategy research protocol.

Before using a tool, read its dedicated tool file. Do not duplicate tool
definitions elsewhere.

Before adding a new tool file, read
[`strategy-research-protocol/tools/toolFile.md`](./toolFile.md).
