Deliberately not ported

  • The simulator's fill, fee and latency model (BacktestExecution.ts, 838 lines). Known wrong: full-size maker fills, no depletion, a free remainder fill, a flat 700 bps fee. The Rust simulator is built from live measurements in N3.
  • The feed-timing constants (110, 320, 2,700 ms in wireBacktestExternalFeeds.ts). Copying them would bake the old bias into the new engine. N7 measures them again.
  • The TypeScript live bot (trading-bot.ts, 1,285 lines). Broken on CLOB V2 since April. The Rust runtime replaces it in N9.
  • The silent contract-address fallback (contractAddresses.ts). On a failed lookup it signs against the retired V1 exchange and USDC.e. Rust pins the V2 and pUSD addresses and refuses to start on a mismatch.
  • Git-SHA worker gating and the exit-75 self-update. They exist because strategies are compiled into worker memory from a checkout. The Rust engine is versioned explicitly.
  • Import-time strategy discovery by regex (strategyRegistry.ts, protocolStrategyDiscovery.ts). Rust registers strategies at compile time.
  • The recorder write path stays TypeScript on purpose: an independent writer is what makes the Rust reader's golden tests mean something.

Import counts between areas confirm the shape: strategies import the strategy SDK 321 times, the CLI imports recorder, backtest, DB and Polymarket clients, and nothing outside the engine imports the trading core except the backtest and the CLI. The Rust engine replaces the inside of that boundary; the TypeScript around it keeps calling through one job contract.
