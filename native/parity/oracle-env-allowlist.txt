# Result-neutral process.env reads under the OR-2 engine paths
# (native/spec/60-verification.md §2.3 OR-7; checked by `npm run native:oracle:env-audit`).
#
# Format: one variable per line, `NAME  # reason`; the reason is mandatory.
# Only variables that cannot change any order, fill, cancel, PnL or stat of a
# backtest belong here. A result-affecting variable missing from the OR-7 table
# is a spec question (STATUS.md "Waiting on user"), never an allowlist entry.
# OR-7 knobs themselves must not be listed here (the audit fails on overlap).

# Live-only: read inside LiveExecution split/merge on-chain paths (src/trading/execution/LiveExecution.ts); backtests run BacktestExecution and never reach them.
POLYGON_RPC_URL  # live-only RPC endpoint for on-chain split/merge in LiveExecution; never read by BacktestExecution
POLYMARKET_TX_MODE_SPLIT  # live-only relayer/direct choice for on-chain split in LiveExecution
POLYMARKET_TX_MODE_MERGE  # live-only relayer/direct choice for on-chain merge in LiveExecution
POLYMARKET_EOA_GAS_MULTIPLIER  # live-only gas multiplier for EOA split/merge transactions in LiveExecution
SPLIT_MAX_RETRY  # live-only on-chain split retry count in LiveExecution
SPLIT_RETRY_DELAY_MS  # live-only on-chain split retry delay in LiveExecution
MERGE_MAX_RETRY  # live-only on-chain merge retry count in LiveExecution
MERGE_RETRY_DELAY_MS  # live-only on-chain merge retry delay in LiveExecution

# Infrastructure: location or connection only.
STRATEGY_ARTIFACT_CACHE_DIR  # cache directory of artifact bundles (src/strategy/artifacts/loader.ts); bundles are sha256-verified, so the location cannot change the code that runs
REDIS_URL  # BullMQ connection target (src/backtest/queue.ts); oracle children never enqueue and R13 forbids the shared fleet Redis
WORKER_LAUNCH_SHA  # fleet worker self-update gate and provenance (src/backtest/commitGate.ts); decides whether a worker takes a job, never how a market is simulated
